# AutoRoute 60 秒演示与录屏脚本

本脚本展示 **发现 → 接入 → 请求 → 收据 → 回退**。先用内置模拟上游录屏，避免费用与私有账号信息；模拟结果必须标为“演示链路”。真实供应商验收和真实 A/B 另行执行，不能用模拟数据替代。

## 录屏前检查

- 使用单独的演示配置目录或全新的演示用户环境，屏幕隐藏账号、私有代码、文件路径和通知。
- 不在画面展示本地 token、供应商 API Key、Keychain、配置备份正文或环境变量。
- 准备 AutoRoute 主窗口、测试台和一个 supported Agent。若未安装 Agent，展示手动 curl 配置，不伪造检测状态。
- macOS 可使用“截屏”App（`Shift-Command-5`）选择“录制所选部分”，录 60 秒；停止后检查音轨与画面。
- 只有在实际生成并审查文件后，才把 GIF/MP4 链接加入 README。当前脚本不代表已有录屏文件。

## 时间线

| 时间 | 操作 | 旁白要点 |
| --- | --- | --- |
| 0–8 秒 | 打开首次引导，点击“使用本地模拟上游” | 仅监听 127.0.0.1；演示不产生外部费用，不计真实成功。 |
| 8–18 秒 | 展示三个健康模型和三档；如需真实发现，明确点击“发现本机模型并测活” | 发现会读取哪些配置并发送轻量测活；不可用模型被剔除。 |
| 18–28 秒 | 打开 Agent 接入，展示脱敏预览、备份并接入 | 保留旧配置，可恢复；稳定别名与独立策略/预算。 |
| 28–38 秒 | 在测试台发送流式请求，随后展示路由收据 | 看实际模型、路由原因、路由耗时、TTFT、总耗时、usage 与费用状态。 |
| 38–50 秒 | 停止一个模拟模型或制造受控失败，再发请求并展示备选成功记录 | 只展示真实发生的回退；SSE 已开始后不跨模型续写。 |
| 50–60 秒 | 打开设置中的本地指标与脱敏导出说明 | 演示、真实和旧版未知记录分开；默认不上传，用户主动导出。 |

不要在失败未发生时声称展示了回退。可以改用两个受控本地上游制造确定失败，并保留对应收据。

## 可复现 A/B 附加段（不计入 60 秒）

公开样例版本：`public-text-v1`。

```text
请用 3 句话总结为什么本地多模型路由器需要区分实测延迟与估算费用。
```

1. 在测试台选择固定基线，启用 A/B，每侧重复 3 次，质量评估先选“未评估”。
2. 确认可能产生真实上游费用后运行。auto 与 baseline 交错执行，每次有独立 session ID。
3. 导出 `autoroute-ab-report.json`，重新解码检查汇总；确认没有提示词、响应正文、API key 或 token。
4. 报告解读只限样本：成本差为 `baseline − auto`，实测与估算分开；缺价格/usage 不按 0 元。未做质量评估时不能声称质量不下降。
5. 真实报告由运行者保存。仓库不提交伪造的“官方成绩”。
